# Windows 11 named CPU review — 0.10.62

The reviewed October 11 CPU list now has explicit categories. Pentium N5000/N5030 and Gold 5405U/6405U are supported/basic-performance upgrade candidates; whole-device eligibility must still be checked. N5000/N5030 use existing-device eligibility, not the current OEM table's omission. Pentium 4415U remains under review. Reviewed old Intel and AMD A-series CPUs are unsuitable under the conservative LaptopLander policy; this is not a claim that every CPU is technically incapable of booting with workarounds.

Apple M1–M4 including listed Pro variants are Mac/virtualization, and Kompanio 500/520/540 are ChromeOS. Neither receives native Windows eligibility. Existing listings update once at startup, locally, without research requests or changes to valuations or queues.
